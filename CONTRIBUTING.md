# Contributing to Bucketeer

Bug reports and feature requests are welcome in [GitHub Issues](https://github.com/tjsanti/Bucketeer/issues).

For a bug, include the version or commit you’re using, the steps to reproduce it, what you expected, and what happened. Use sample data and remove personal or financial details from screenshots and logs.

Bucketeer is open source and you’re welcome to fork it under the [AGPL](LICENSE). I don’t accept pull requests or patches for this repository. I write the fixes myself so I can choose distribution terms for the planned iOS and macOS apps. If you’ve found the cause of a bug or have an idea for a fix, please describe it in the issue.
