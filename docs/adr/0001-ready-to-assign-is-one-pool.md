# Ready to assign is one pool across all months

Ready to assign is a single, budget-wide pool: starting balances + Income − everything ever assigned from it, in any month. It is not one pool per month with leftovers rolling forward. Assigning into a future month draws from the same pool, so every month's page shows the same, lower figure. We chose one pool because it answers the only question that matters ("how much can I still give out?") and leaves no per-month leftovers to reconcile.

Ready to assign may go negative, for example when an Income transaction is edited down after the money was assigned. It is shown in the overspent red with a true minus sign. Refusing the edit would be worse.
